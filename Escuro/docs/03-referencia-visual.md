# Referência Visual

## Arquivos

- Layout de referência: `docs/assets/referencias/front-referencia.png`
- Logo: `docs/assets/referencias/logo-escuro.png`

## Direção visual

- Tema escuro;
- vermelho como cor principal;
- aparência de painel administrativo;
- navegação lateral fixa;
- cards e tabelas com contraste moderado;
- botões de ação em vermelho;
- badges para status como `ATIVO`, `SUSPENSO` e `ENCERRADO`;
- interface de atendente, sem telas técnicas de teste da API.

## Telas planejadas

- Login;
- Dashboard;
- Novo Contrato;
- Contratos;
- Detalhes do Contrato;
- Clientes;
- Planos.

## Observações importantes

O front-end deve simular uma rotina operacional. Payloads, cURL, console técnico, códigos HTTP e testes da API ficam no Swagger e no Postman, não na interface do atendente.
