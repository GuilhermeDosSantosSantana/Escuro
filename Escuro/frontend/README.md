# Front-end Escuro

Interface interna fictícia para rotina de atendente.

## Telas planejadas

- Login;
- Dashboard;
- Novo Contrato;
- Contratos;
- Detalhes do Contrato;
- Clientes;
- Planos.

## Direção de interface

- Tema escuro;
- vermelho como cor principal;
- navegação lateral;
- tabelas operacionais;
- formulários claros;
- mensagens amigáveis;
- sem payloads técnicos, cURL ou console de API.

## Execução local

```bash
npm install
npm run dev
```

Se a API estiver rodando em uma porta alternativa:

```powershell
$env:VITE_API_BASE_URL="http://127.0.0.1:3334"; npm run dev
```

## Build

```bash
npm run build
```
